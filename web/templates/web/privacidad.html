Información institucional

Política de privacidad

TRADICIÓN VIVA utiliza los datos proporcionados por sus usuarios para gestionar registros, turnos, comunicaciones y servicios relacionados con las hermandades participantes.

Datos que podemos solicitar

Nombre, documento de identificación, datos de contacto, información de registro y, cuando corresponda, la medida visual necesaria para la organización de turnos.

Uso de la información

La información se utiliza para administrar la participación, enviar comunicaciones autorizadas, generar comprobantes y mejorar la coordinación de las actividades.

Protección y derechos

Se aplican controles de acceso, sesiones protegidas, registro de actividad administrativa y respaldos periódicos. Puedes solicitar consulta, corrección o aclaración sobre tus datos escribiendo a tradicionvivagt@gmail.com.

Consentimiento

Antes de completar un registro, la persona debe leer y aceptar esta política. El consentimiento se almacena junto con el registro y puede actualizarse desde el panel de devoto. Las comunicaciones por correo electrónico o WhatsApp solo se envían cuando fueron autorizadas expresamente.

Conservación y eliminación

Los datos se conservan durante el tiempo necesario para administrar la participación en la organización correspondiente. Las solicitudes de actualización o eliminación se revisan por el personal autorizado.
