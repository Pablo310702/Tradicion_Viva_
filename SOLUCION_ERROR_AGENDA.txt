MIGRACIONES DE BASE DE DATOS

Este paquete incluye las tablas de agenda, devotos y contenido administrable en db.sqlite3.

Cuando copies los archivos sobre una instalación existente, detén primero el servidor de Django y ejecuta desde la carpeta donde está manage.py:

    py configurar_local.py
    py manage.py migrate

Migraciones nuevas:
- hermandades.0004_seguridad_contenido_devotos
- hermandades.0005_alter_hermandad_logo_alter_hermandad_portada_and_more

Después inicia el servidor:

    py manage.py runserver

El comando migrate crea las tablas nuevas sin borrar los datos existentes. Realiza una copia de seguridad de db.sqlite3 antes de reemplazar archivos en producción.
