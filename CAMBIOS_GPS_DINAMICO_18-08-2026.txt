TRADICIÓN VIVA - GPS DINÁMICO POR HERMANDAD
Fecha: 18/08/2026

CAMBIOS REALIZADOS
1. Se eliminaron los IDs de dispositivo Traccar fijos por slug en web/views.py.
2. Se agregaron a Hermandad los campos:
   - gps_activo
   - traccar_device_id
   - nombre_dispositivo_gps
3. El administrador de Django permite activar/desactivar GPS y asignar el dispositivo a cualquier hermandad, incluso una creada posteriormente.
4. La API /api/<slug>/ubicacion/ obtiene el deviceId directamente de la base de datos.
5. El seguimiento deja de consultar Traccar cada 8 segundos cuando la hermandad no tiene GPS configurado.
6. Las credenciales globales de Traccar siguen en .env; los IDs por hermandad ya no van allí.
7. Se agregó la migración 0007_hermandad_gps_dinamico.py.

DESPUÉS DE DESCOMPRIMIR
1. Activa tu entorno virtual.
2. Ejecuta: python manage.py migrate
3. Ejecuta: python manage.py check
4. Ejecuta: python manage.py runserver

CONFIGURAR GPS
1. Abre /admin/ e inicia sesión.
2. Entra a Hermandades y cofradías.
3. Abre la organización deseada.
4. En Seguimiento GPS / Traccar:
   - Marca "seguimiento GPS activo".
   - Escribe el ID numérico del dispositivo de Traccar.
   - Opcionalmente escribe un nombre descriptivo.
5. Guarda.

CONFIGURACIÓN GLOBAL EN .env
TRACCAR_BASE_URL=https://tu-servidor-traccar.example
TRACCAR_USERNAME=usuario@example.com
TRACCAR_PASSWORD=tu_clave

IMPORTANTE
Los dispositivos nuevos (Traccar Client, Teltonika u otro compatible con Traccar) se vinculan a una hermandad desde el administrador, sin modificar Python, URLs ni settings.py.


ACTUALIZACIÓN - ID COMPARTIDO
El campo traccar_device_id ya no es único: el mismo dispositivo puede asignarse a varias hermandades/cofradías.
Ejecutar python manage.py migrate para aplicar la migración 0008.
