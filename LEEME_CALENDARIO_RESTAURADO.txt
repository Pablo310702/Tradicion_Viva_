TRADICIÓN VIVA — CALENDARIO RESTAURADO

Esta versión conserva:
- Agenda visual con vistas Mes, Semana y Día para las cuatro organizaciones.
- Calendario HTML de respaldo: aunque JavaScript no cargue, el mes actual sigue visible.
- Seguimiento en vivo dentro del menú Recorrido en todas las secciones.
- Editor de turnos protegido para usuarios staff/superusuarios.
- Registro real de devotos y mejoras de seguridad.

INICIO RECOMENDADO EN WINDOWS
1. Extrae esta carpeta con un nombre nuevo. No la extraigas encima de una carpeta que tenga Django ejecutándose.
2. Haz doble clic en iniciar_local.bat.
3. El archivo crea .venv y usa ese entorno aislado, evitando bloqueos del Python global.

INICIO MANUAL
  py -3.13 -m venv .venv
  .venv\Scripts\python.exe configurar_local.py
  .venv\Scripts\python.exe -m pip install -r requirements.txt
  .venv\Scripts\python.exe manage.py migrate
  .venv\Scripts\python.exe manage.py runserver

AGENDA
  http://127.0.0.1:8000/hermandad/rosario-merced/agenda/
  http://127.0.0.1:8000/hermandad/san-jose/agenda/
