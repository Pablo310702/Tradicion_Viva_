TRADICIÓN VIVA — SEGURIDAD, REGISTRO Y CONTENIDO

CAMBIOS APLICADOS

1. CONFIGURACIÓN SEGURA
- SECRET_KEY ya no tiene ningún valor incrustado en settings.py.
- DEBUG, ALLOWED_HOSTS y CSRF_TRUSTED_ORIGINS se leen desde variables de entorno.
- Se eliminó el identificador GPS real que estaba como valor predeterminado.
- Se añadieron cookies seguras, redirección HTTPS, HSTS y cabeceras de seguridad para producción.
- Los errores internos de Traccar ya no se muestran al público.
- Ejecuta "python configurar_local.py" una sola vez para crear un archivo .env local con una clave aleatoria.

2. ARCHIVOS ESTÁTICOS
- WhiteNoise está habilitado inmediatamente después de SecurityMiddleware.
- En producción se usa CompressedManifestStaticFilesStorage mediante STORAGES.
- build.sh ejecuta check --deploy, collectstatic y migrate.

3. REGISTRO REAL DE DEVOTOS
- El formulario ahora envía POST con CSRF y guarda los datos en la base de datos.
- Nuevo modelo Devoto asociado a cada hermandad o cofradía.
- Validaciones del lado del servidor: DPI de 13 dígitos, fecha real, celular, correo confirmado, privacidad y duplicados.
- El DPI se muestra enmascarado en la lista de Django Admin.
- La referencia visual de hombro se guarda como cantidad de píxeles; no representa centímetros reales.

4. INTERFAZ Y MAPA
- Se entrega nombre_corto a la plantilla y ya no queda vacío.
- El cálculo del turno más cercano usa Haversine en metros.
- Las consultas de agenda y turnos usan select_related y filtros específicos.
- Se eliminaron las plantillas antiguas duplicadas de San José.

5. CONTENIDO ADMINISTRABLE
- Hermandad ahora incluye Misión, Visión e Información del templo.
- Nuevos modelos administrables: Imágenes, Videos y Marchas procesionales.
- Las imágenes aceptan JPG, JPEG, PNG o WEBP, máximo 5 MB, y generan miniatura.
- Los audios aceptan MP3, M4A, OGG o WAV, máximo 20 MB.
- Los videos de YouTube se incrustan con youtube-nocookie.com.

6. SEO Y REDES SOCIALES
- Metadatos Open Graph y Twitter Card en las páginas principales.
- sitemap.xml dinámico.
- robots.txt con bloqueo del panel /admin/.

7. PRUEBAS
- Se agregaron 10 pruebas automáticas para registro, agenda, editor administrativo, SEO y modelos.
- Resultado de validación: 10 pruebas aprobadas y comprobación de despliegue satisfactoria.
- HSTS para subdominios y preload quedan desactivados por defecto; actívalos solo cuando todo el dominio y sus subdominios usen HTTPS.

PRIMER INICIO EN WINDOWS
1. Abre una terminal dentro de la carpeta del proyecto.
2. Ejecuta: py configurar_local.py
3. Ejecuta: py -m pip install -r requirements.txt
4. Ejecuta: py manage.py migrate
5. Ejecuta: py manage.py runserver

También puedes ejecutar iniciar_local.bat.

PRODUCCIÓN
Configura como mínimo estas variables en el servidor:
SECRET_KEY, DEBUG=False, ALLOWED_HOSTS, CSRF_TRUSTED_ORIGINS y DATABASE_URL.
No copies el archivo .env local al servidor ni lo publiques en Git.
